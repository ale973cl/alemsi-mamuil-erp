ALEMSI ERP · v2.1.3.35 CANDIDATA PRODUCCION DEMO

Candidata de cierre para demo/pruebas reales con personas.

Subir el contenido completo de esta carpeta al repositorio.

Antes de limpiar datos de prueba:
1. Generar respaldo desde AdminTotal > Respaldo.
2. Descargar el ZIP de respaldo y verificar el mensaje de Drive.
3. Probar login, Minutas, Coordinación, Finanzas y Producción.
4. Recién después usar AdminTotal > Depuración > Preparar base para producción.

La limpieza conserva Minutas, Platos, Recetas, Usuarios, Instituciones, permisos y configuración.
