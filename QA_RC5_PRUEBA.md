# ALEMSI v2.1.3.42-RC5

Candidata de prueba acumulativa.

## Correcciones
- Reserva: mínimo día siguiente; hoy queda fuera de plazo.
- Validación backend adicional antes de insertar/actualizar reservas.
- Pago y reserva quedan tratados como estados independientes.
- Una reserva comercial activa con pago no validado bloquea nuevas reservas.
- Una reserva futura pagada permanece activa para consumo/Producción.
- Carga de comprobante refresca inmediatamente la pantalla.
- Conflictos de minuta quedan como alerta no bloqueante.
- Revisar/Auditar y Enviar a Coordinación no se bloquean por coincidencias de opciones.
- Publicación sigue exigiendo autorización de Coordinación.
- Bodega no fue modificada.
